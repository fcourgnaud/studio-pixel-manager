# Studio Pixel — Manager (version en ligne)

Ce dépôt contient seulement le code de l'application de suivi de production de Studio Pixel.
Il ne contient aucune donnée de projet : celles-ci sont enregistrées dans un dépôt privé,
avec une clé d'accès que seule la propriétaire possède.

Ne pas modifier ce dépôt à la main : il est régénéré à partir du dépôt privé
(script `Outils/preparer_manager_public.py`).
